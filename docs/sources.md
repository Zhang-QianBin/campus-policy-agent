# 政策样本来源清单

本清单记录杭州电子科技大学首批政策样本的发布页面、网页正文和附件，用于后续解析、检索与问答实验。

## 整理约定

- 每个发布页面对应一个稳定编号 `policy-NNN`；同一页面的正文和附件放在同一个样本目录内。
- `body.md` 保存人工整理的网页正文，`attachments/` 保存下载的原始附件；没有附件的页面不必创建附件目录。
- 本文中的本地链接均相对于 `docs/sources.md`，不包含个人电脑的绝对路径。
- 发布日期、来源和发布者沿用现有人工记录，本次仅核对本地文件结构，未重新核验网页内容。采集时间尚未记录，后续应填写实际保存时间。
- 样本已保存不等于解析成功；PDF、Excel 等文件的文字提取与检索效果需在后续实验中验证。
